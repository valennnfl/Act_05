
# Act_05 - Tienda online

Actividad 5 de Sistemas Operativos (DWM3AP).

## Descripción
Sitio web de una tienda online de ropa, maquillaje, cuidados y joyería. Muestra un catálogo de productos cargados desde un archivo JSON, con buscador, filtros por categoría y carrito de compras.

## Funcionalidades
- Listado de productos con imagen, precio, nombre y descripción
- Buscador de productos por nombre
- Filtro por categoría: Todas, Ropa, Maquillaje, Cuidados y Joyería
- Botón "Agregar al carrito"
- Página de carrito
- Navegación entre Inicio, Productos y Carrito

## Tecnologías
- HTML
- CSS
- JavaScript

## Estructura del proyecto
- `componentes/`: componentes reutilizables (por ejemplo, la barra de navegación)
- `css/`: estilos
- `fonts/`: tipografías
- `img/`: imágenes de los productos
- `app.js`: lógica principal (carga de productos, filtros, buscador y carrito)
- `index.html`: página principal
- `productos.json`: datos de los productos

## Cómo ejecutarlo
1. Clonar el repositorio:
   `git clone https://github.com/valennnfl/Act_05.git`
2. Abrir la carpeta en VS Code.
3. Abrir el proyecto con la extensión **Live Server** (clic derecho en `index.html` → *Open with Live Server*), porque los productos se cargan desde un JSON y necesita un servidor local.
